
# Hangman Game

A simple word-guessing game built with Python and Tkinter.

## Features

- Graphical user interface (GUI)
- Clickable QWERTY keyboard
- Physical keyboard support
- Word categories and clues
- Stick-figure Hangman drawing
- Six incorrect guesses allowed
- New Game option

## Technologies Used

- Python
- Tkinter
- Random module

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```
